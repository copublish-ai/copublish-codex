# copublish for Codex

Pointer files for the copublish skills. Each one only names a skill and tells Codex to ask the copublish
server for the full instructions when the skill is used. This repo is generated: do not edit it by hand.

Install: `codex plugin marketplace add grantwyatt/copublish-codex`, then install copublish from `/plugins`.
This installs the skills only. Connect the copublish server separately, with your key from your copublish
account page (the account page shows the exact command; the key goes in COPUBLISH_KEY).

Privacy: https://copublish.ai/privacy
